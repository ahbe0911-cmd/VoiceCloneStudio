# VoiceCloneStudio

Android Kotlin prototype for recording or selecting a reference voice, entering Persian text, and sending it to a voice-cloning backend.

**Important:** This repository currently contains the Android project setup only. Voice cloning requires a separately deployed and configured backend. Only clone voices with permission.

## Build

GitHub Actions builds a debug APK after the Android project files are added. The APK will be available in the workflow run's Artifacts section.
